Salta 2026 - Rick and Morty Theme job

Proyecto académico desarrollado para la profesionalización en JavaScript, aplicando técnicas avanzadas de manipulación del DOM, consumo de APIs y diseño responsivo con una estética inspirada en Rick and Morty.
🚀 Páginas del Proyecto

    Catálogo de Productos (productos.html): Tienda dinámica que permite filtrar productos por nombre, categoría y rango de precio en tiempo real.

    Lista de Tareas (todo.html): Administrador de tareas personal con persistencia lógica y contador de pendientes.

    API Multiverso (opi-demo.html): Aplicación que consume la Rick and Morty API para visualizar personajes, su estado y origen.

🛠️ Tecnologías Usadas

    HTML5: Estructura semántica.

    CSS3: Diseño profesional mediante Variables (:root), Flexbox y Grid Layout.

    JavaScript ES6+: Lógica interactiva y manejo de eventos.

    Fetch API: Consumo asíncrono de recursos.

    API Elegida:(https://rickandmortyapi.com/).

📸 Funcionalidades Clave

    Diseño Neón: Interfaz de alto contraste (Negro/Verde) con efectos de resplandor.

    Feedback Visual: Estados de carga (texto pulsante), mensajes de error y estados vacíos.

    Responsividad: Adaptación completa a dispositivos móviles.

⚙️ Instrucciones de Uso

⚙️ Instrucciones de Uso de las paginas

  Opi-demo.html 
  
  Es una base de dato de los personajes de Rick y Morty, pimero te muestra todos por defecto, pero puedes buscar por personaje en espesifico o por variantes del mismo, a su ves de ver datos en la actualidad segundo el canon de la hisotoria (aun que siguiendo algunos datos esta desactualizado)

  Todo.html 
  
  Es una pagina con la caracteristica de poder marcar y determinar tareas pendientes con cualquier tipo de prosito que requiera tareas a concretar, te muestra cuantas hay pendientes, puedes agregar las que quieras realizar y eleminzar aquellas que ya esten realziadas

  Productos.html
  
  Es una pagina donde pudes observar los productos en venta que dispone la empresa/pagina y determinar cuaales puedes acceder determinando tu presupuesto disponible de forma manual con una barra reguladora de preccio, ademas de poder observar si esta disponible o no en la tienda para descartar productos

  Esta breve eplicacion de la pagina es lo que determina como usarlas
